## What this means for the claim structure

* The file's **claim 1** (guard with validated, entity-derived bound, hold, shadow, promote) is our claims 1 and 2 plus the link, with the measured limits above.
* The file's **claim 2** (explanation) is demoted to a dependent feature with the measured results: reproducibility is real and cheap to claim; accuracy is modest and conditional.
* The file's **claim 3** (attribution against the snapshot) is a dependent feature with the condition under which it helps.
* **Invention C** (schema-free) is not claimed: the real-data test is negative.
* **Cohort seeding** is the one element of the file that gains from the scope change.
